# 🤖 Chatbot Carmen

Bem-vindo ao repositório do **Chatbot Carmen**! Este é um projeto de uma assistente virtual desenvolvida para conversar com o usuário.

## 📋 Sobre o Projeto

A **Carmen** foi criada com o intuito de aplicar conceitos de Lógica de Programação, Inteligência Artificial e Estruturas de Dados. O foco principal é oferecer uma interface amigável e respostas rápidas para o usuário.

**Funcionalidades principais:**
* **Interação em Linguagem Natural:** O usuário pode conversar livremente.
* **Respostas Rápidas:** O sistema foi otimizado para responder em tempo real.

## 🛠️ Tecnologias Utilizadas

* [Linguagem Principal: Python 3]
* [Bibliotecas: Tkinter]
* [IDE/Ferramentas: VS Code]
